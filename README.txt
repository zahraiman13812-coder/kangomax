How to use:
Open index.html in a modern browser, or upload the contents of this folder to the root of a GitHub repository and import that repository into Vercel.
This is a static HTML/CSS/JavaScript website. No build command is required; use the project root as the Vercel root directory.

Design:
Warm ivory, muted sage, graphite and gold palette (not a black background), responsive desktop/tablet/mobile layouts, mobile navigation, animated reveal, package image lightbox, FAQ accordion.

Content accuracy and safety:
Product facts and amounts are transcribed from the supplied KANGOMAX package images. The label states 60 tablets, Made in Thailand, and ingredient amounts per 2 tablets. The label lists RAD-140 (Testolone) and YK-11 (Myostine). The website prominently identifies these as investigational/SARM-related compounds and does not claim safety, efficacy, approval, certification, or independent authenticity. The package's "suggested use" is not presented as a recommendation to consume.
